Projeto de Programação Web

Sinerge — Empresa Simulada

Esta página reúne os trabalhos desenvolvidos pelos estudantes do 1º ano, simulando os setores de uma empresa. Cada grupo ficou responsável por um departamento e criou sua página usando HTML e CSS, publicada pelo GitHub Pages.

Sobre o projeto

Os estudantes foram organizados em 4 grupos, cada um representando um setor da empresa Sinerge. O desafio foi criar páginas estáticas que apresentassem o departamento, suas funções e sua importância dentro da organização.

Além da construção das páginas, o trabalho aproximou os estudantes do processo real de publicação de um site, utilizando repositórios no GitHub e o GitHub Pages para disponibilizar o conteúdo na internet.

HTML

Estruturar o conteúdo da página com títulos, parágrafos, links, imagens e seções.

CSS

Aplicar estilos para melhorar a aparência, o espaçamento, as cores e a organização visual.

Organização

Separar os arquivos do projeto em pastas e manter uma estrutura clara para publicação.

Publicação

Disponibilizar os trabalhos na internet usando repositório no GitHub e GitHub Pages.
