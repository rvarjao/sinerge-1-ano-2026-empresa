Projeto de Programação Web

Trabalhos dos Estudantes do 1º Ano

Esta página reúne os trabalhos desenvolvidos pelos estudantes do 1º ano utilizando páginas estáticas com HTML e CSS. O objetivo foi praticar a criação de páginas web, organização de conteúdo, uso de links, estrutura visual e publicação na internet por meio do GitHub Pages.

Resumo do trabalho

Durante o desenvolvimento deste projeto, os estudantes foram desafiados a criar páginas estáticas para apresentar um tema, uma empresa, uma equipe ou uma proposta definida em aula. Cada grupo organizou suas informações em seções, utilizando títulos, textos, imagens, listas, links e elementos visuais básicos.

Além da construção das páginas, o trabalho também teve como objetivo aproximar os estudantes do processo real de publicação de um site. Para isso, os arquivos foram preparados em HTML e CSS e disponibilizados em um repositório no GitHub, permitindo que cada página pudesse ser acessada publicamente pelo GitHub Pages.

HTML

Estruturar o conteúdo da página com títulos, parágrafos, links, imagens e seções.

CSS

Aplicar estilos básicos para melhorar a aparência, o espaçamento, as cores e a organização visual.

Organização

Separar os arquivos do projeto em pastas e manter uma estrutura clara para publicação.

Publicação

Disponibilizar os trabalhos na internet usando repositório no GitHub e GitHub Pages.
